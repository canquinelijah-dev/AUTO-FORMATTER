Documentation

Project: CvSU ThesisForge · Course/Section: ______ · Group members: ______ · Submitted: ______

Problem: Students spend time manually reformatting papers to instructor specifications. General objective: a browser-only tool that applies configurable formatting to a student’s own document. Specific objectives: (1) rebuild a valid .docx from an uploaded .docx or text file within 10 s for files up to 10 MB; (2) provide 5 document-type presets, all editable; (3) clear all document references 10 minutes after selection.

Architecture: HTML, CSS and vanilla JavaScript only. No backend, database, login or permanent storage. Documents are processed in the browser tab; each user and tab is independent. Cleanup removes this page’s references and Blob URLs but cannot guarantee deletion from browser/OS memory or from files you already downloaded.

Target users: CvSU students. Scope: formatting only; it never writes or invents content or citations.

Limitations (honest list)
  • PDF cannot be reliably reconverted to editable paragraphs without a PDF library; legacy .DOC is a binary format. Workaround: Save as DOCX first.
  • DOCX output keeps paragraphs, headings (Heading styles), bold/italic, simple tables and code lines. Images, footnotes, text boxes, equations, lists numbering and existing headers/footers are not carried over; the app lists what it detected so nothing is dropped silently.
  • Headings are only recognized when the source uses Word Heading/Title styles.
  • Print headers/footers use CSS page margin boxes (Chromium-based browsers); other browsers may omit them.
  • Not yet tested: this build was generated without running a browser. Test upload, download, timer, mobile layout and multi-tab behavior yourself before submitting.
